# Автоматизация развертывания веб-инфраструктуры (Bash)

Репозиторий содержит набор Bash-скриптов для автоматической настройки и конфигурации трех серверов (VPS).

## Архитектура проекта
* **VPS 1 (Nginx):** Настроен как Reverse Proxy (обратный прокси-сервер) для перенаправления трафика на бэкенд.
* **VPS 2 (Apache):** Выступает в роли Backend-сервера для обработки динамического контента.
* **VPS 3 (MySQL):** Выделенный сервер баз данных для хранения данных приложения.

## Описание скриптов
* `clean_server.sh` — базовая очистка и подготовка серверов к установке ПО.
* `install_nginx.sh` — установка Nginx и настройка проксирования на VPS 1.
* `install_apache.sh` — развертывание веб-сервера Apache на VPS 2.
* `install_db.sh` — установка и базовая безопасность СУББД MySQL на VPS 3.

## Как использовать
Скрипты запускаются локально на каждом целевом сервере из-под пользователя с правами `sudo`.
